## 만들 것
- vague에서 "as soon as …"(조건이 붙은 즉시 행동)는 빼고, 홀로 쓴 "soon"("It should arrive soon", "soon")은 그대로 잡는다. 한국어 "받는 대로 바로"·"받으시면 바로"류도 모호함이 아님(지금 안 잡히면 그대로).
- 시험: "as soon as I receive it" → vague false / "It should arrive soon." → true / 시안 rushed 글 → true / 서연 AI 초안(캐시 초안 영어) → vague false.
