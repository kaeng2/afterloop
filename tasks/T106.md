## 고칠 것
1. **F1-18 · F1-19 · F1-47** 목록 항목·상품 칩 클릭을 **화면 안 상태로 바로** 바꾼다 (서버 왕복 없이). 데이터는 처음 한 번 받아 둔다 (첫 요청에서 목록 항목들의 상세를 모두 그려 두고 고른 것만 보이기 등). 주소(`?item`·`?sku`)는 `history.replaceState` 등으로 맞춰 새로고침·공유 때 같은 화면. **칩을 눌러도 고른 사건은 유지**(시안 L688). 칩은 `<button aria-pressed>`(시안 L111), 항목은 `<button>`(시안 L141) — 키보드 접근 유지.
   - 화면 상태(T102 Done today·T091 "+$N just now"·서연 답장 칸 상태)가 항목을 오가도 유지되면 더 좋다 (서연 답장 칸이 다시 그려지며 상태를 잃지 않게 — 숨김으로 두기 권장).
   - 첫 화면 속도가 크게 나빠지면(지금 대비 +1초 이상) 보고서에 수치와 함께 적는다.
2. **F1-55 · F1-56 · F1-58** 지호·추적 상세를 시안의 짧은 **zone-work 카드 틀**로 (시안 L345-357: 52px 타일 + h1 24px 900 + 범주 칩 + who 14px, 아래 .zone-work 카드 r24·padding 22/22/20·그림자·위 4px 그라데이션 띠·AI 알약·제목 20px·설명 15px #3F4144·검정 .btn). 
   - 지호: 제목 = 엔진 제안(대명사 없이 이름 규칙, v2.15 결정), [Send offer] → 승인 관문 그대로 → 끝나면 "Offer sent ✓" 꺼짐 + Simulated 표시. 지금 전체 사건 데스크(곡선·기록 등)는 지호에 보이지 않는다. 옛 "Escalation risk · Score 0" 줄 없앤다.
   - 추적: 제목·설명·[Add all N] (주문 표는 Details 같은 접힘 안으로 두거나 카드 아래 작게 — 데이터는 지우지 않는다).
   - Mike(routine)·상품(prevent) 상세도 같은 틀이면 좋다 (시간 남으면).
3. **F1-59** 추적 버튼 누른 뒤: 즉시 꺼짐 + "Added ✓"(Simulated이면 그 표시 유지), 다시 누를 수 없음.
4. **F1-63** 저장 금액 0인 완료에도 시안처럼 토스트(완료 문구, 금액 없이).
5. **F1-22** 처리 뒤 상품 칩 배지와 "N open cases"를 화면 상태로 줄인다 (T102 done 상자 기준, 새로고침하면 원래대로. 숫자는 데이터 개수에서 done 개수를 빼는 셈이 아니라 done이 아닌 항목 수를 세는 것으로).
