> **가장 중요한 규칙**
> 1. 이 worktree 루트의 `.env`는 어떤 방법으로도 열거나 출력하지 않는다. **실제 AI 호출 금지** — 가짜 `LlmCaller`만. 병합 뒤 컨트롤 타워가 실제 AI로 확인하고 캐시를 만든다.
> 2. 요약은 **입력 사건에 있는 사실만**. 사건을 지어내지 않고, 판매자에게 약속을 권하지 않는다 (환불·재발송·할인 등 — T053 `findCommitments`로 막는다).

## 수정 가능 폴더
- `src/ai/history.ts` (새), `src/ai/prompts/history.ts` (새), `tests/unit/history.test.ts` (새)

## 만들 것
```ts
summarizeCaseHistory(
  input: { events: CaseEvent[]; buyerFirstNameToken?: string; locale: 'en' },
  deps: { llm: LlmCaller },
): Promise<{ ok: true; summary: string } | { ok: false; reason: 'ai_unavailable' | 'invalid_output' }>
```
- 프롬프트: 사건 목록(날짜·종류·한 줄·표시)을 넘기고, 판매자가 지금 알아야 할 것을 **영어 1~2문장, 240자 이내**로. 예시 꼴(실제 값 없이): "She has asked twice with no reply, and the parcel is held at customs; reply in her language and give the follow-up date." — 사람 이름은 넘기지 않는다(필요하면 `⟦BUYER_NAME_1⟧` 토큰만, T056 규칙).
- 코드 검사 (실패면 `invalid_output`, 화면은 그 줄을 숨긴다):
  - 출력의 날짜·숫자는 모두 입력 사건(날짜·글)에 있는 것이어야 한다 (월 이름+일, M/D, 숫자 — 입력에 없으면 실패)
  - 약속 낱말(`findCommitments`)이 있으면 실패
  - 길이·문장 수 초과면 실패, 꺾쇠·태그 글자 제거 (T050 한 줄 처리 재사용)
- JSON 스키마로 받는다 (`{ summary: string }`), zod 검증.

## 완료 기준 (가짜 `LlmCaller`만)
- [ ] 정상: 입력 사건 날짜만 쓴 요약 → ok
