## 만들 것
```ts
export type FixSaving = { fix: FixId; on: boolean; savingCents: number };
export function fixSavings(input: SimInput /* 지금 켠 처방 = input.fixes */, params?, rules?): FixSaving[]   // FIX_ORDER 순서
```
- 켜진 처방: `savingCents = meanLoss(지금 켠 것에서 이 처방만 끈 것) − meanLoss(지금 켠 것)` ("이걸 끄면 이만큼 늘어난다")
- 꺼진 처방: `savingCents = meanLoss(지금 켠 것) − meanLoss(지금 켠 것 + 이 처방)` ("이걸 켜면 이만큼 줄어든다")
- 같은 시드·같은 미래(지금 `simulate`와 같은 난수) — 결정적. 음수가 나오면 그대로 돌려주되 테스트에 기록 (처방 배수 ≤ 1이라 보통 0 이상).
- 0.5초 안 (지금 토글 재계산과 같은 크기 — 처방 4개면 `simulate` 최대 5번).

## 완료 기준
