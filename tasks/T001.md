## 수정 가능 폴더
- `.env.example` (새 파일)
- `.gitignore`: `!.env.example` 한 줄 추가만 (지금 `.env*`가 `.env.example`까지 무시함)
- `package.json`: `scripts`에 `"sandbox:check"` 한 줄 추가만
- `scripts/sandbox/`
- `tests/sandbox/`
- `tests/fixtures/` (개인정보 제거한 응답만)

이 밖은 수정하지 않는다. 특히 `src/`, `SPEC.md`, `src/types.ts`, `tests/acceptance/`, `tasks/`, `TASKS.md`.

## 목표
새로 받은 사람이 `.env`만 채우면 `npm run sandbox:check` 한 번으로 샌드박스 연결(토큰, 분쟁 목록, 분쟁 상세)을 확인할 수 있게 한다.

## 입력 / 출력
- 입력: `.env`의 `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `PAYPAL_BASE_URL` (`https://api-m.sandbox.paypal.com`만 허용)
- `.env.example`: 위 세 키와 `ANTHROPIC_API_KEY` 자리 (값은 비움), 각 키를 어디서 받는지 한 줄 주석
- `scripts/sandbox/check.ts` (`npx tsx`로 실행)
  1. `POST /v1/oauth2/token` (client_credentials)
  2. `GET /v1/customer/disputes?page_size=5`
  3. `GET /v1/customer/disputes/PP-R-XWI-10197379` (기존 테스트 분쟁)
  - 사람용 출력: 단계별 상태 코드, 분쟁 수, 분쟁 상세의 `status`·`dispute_life_cycle_stage`·`links[].rel` 목록
  - `--json` 옵션: `{ "token": { "ok": boolean }, "list": { "status": number, "count": number }, "detail": { "status": number, "disputeId": string, "rels": string[] } }` 한 줄만 출력 (AC13이 이 형식을 읽는다)
  - 결과 요약(엔드포인트, 상태 코드, 분쟁 ID, 시각)을 `tests/sandbox/last-run.md`에 덮어쓴다
  - `PAYPAL_BASE_URL`이 샌드박스가 아니면 호출하지 않고 종료 코드 1
- 이 단계에서는 `fetch`를 직접 쓴다. 재시도·속도 제한·토큰 재사용은 T002가 `src/paypal/client.ts`로 만들고, 그때 이 스크립트를 클라이언트로 바꾼다.

## 완료 기준
- [ ] `npm run sandbox:check`가 세 단계 모두 200으로 끝난다 (실행 결과를 보고서에 붙인다. 토큰 값은 빼고)
- [ ] `npx tsx scripts/sandbox/check.ts --json` 출력이 위 형식과 같다
- [ ] 출력, `last-run.md`, 에러 메시지 어디에도 Client Secret·액세스 토큰 값이 없다 (잘못된 Secret으로 한 번 실행해서 에러 메시지도 확인)
- [ ] `.env.example`이 git에 들어가고 `.env`는 들어가지 않는다 (`git check-ignore .env` → 무시됨, `.env.example` → 무시 안 됨)
- [ ] 인수 테스트 **AC13** 통과 (`RUN_SANDBOX=1 npm run test:acceptance`). ⚠ AC13은 컨트롤 타워가 작성·승인 후 배정한다. 아직 없으면 위 체크 항목까지만 하고 보고한다

## 하지 않을 것
- 분쟁 상태를 바꾸는 호출: send-message, make-offer, accept-claim, provide-evidence, escalate, adjudicate. **조회만 한다**
- 샌드박스 구매자 계정 로그인, 새 분쟁 만들기 (사람이 한다)
- OAuth 재시도, 429 처리, 속도 제한 (T002)
- `.env` 커밋, 비밀값을 보고서에 적기

## 참고
- 메모: Transaction Search(`/v1/reporting/transactions`)는 이 앱 권한이 없어 403. 이번 작업에서 부르지 않는다.
- 판매자 계정은 KR. 테스트 결제는 비 KR 구매자 계정으로만 가능하다.
