## 만들 것
```ts
export type PreventPick = { sku: string; beforeCents: number; afterCents: number; cutPercent: number };
export function pickPreventProduct(store: StoreTotal): PreventPick | null
```
- 대상: `store.products` 중 `before.meanLossCents > 0`인 상품.
- 기준: `(before − after) / before`가 가장 큰 상품. 나눗셈 대신 교차 곱으로 비교(정수, 부동소수 오차 없음). 같으면 `before`가 큰 쪽, 그것도 같으면 입력 순서 앞.
- `cutPercent` = `round((before − after) × 100 / before)` (정수). 대상이 없으면 `null`.
- 순수 함수. 설정을 읽지 않는다.
