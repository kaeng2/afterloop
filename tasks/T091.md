> **가장 중요한 규칙**
> 1. **화면은 계산하지 않는다.** 숫자는 엔진(`forecastReply`·`forecastMoves`·`riskCurve`·`replyFeatureEffects`·`actionSavings`·`trackingSavings`·`recommend`)에서만. 표기만 화면.
> 2. **실제 환불·실제 전송 없음**: 환불 카드 = "Refund done · Simulated". 제안 버튼의 승인 관문·보내기 관문·데모 모드 그대로. 공개 모드 Add all N = Simulated, 분쟁 걸린 주문 제외 유지.
> 3. 넣는 문장은 `config/reply-snippets.json`(T093)만. 금액·날짜·이름은 자리표시자로 두고 코드가 채운다. "Refund backup"·"Expected delivery" 없음.
> 4. 실제 AI·PayPal 호출 금지(가짜로 시험), 개발 서버 금지. `.env` 읽지 않음.

## 만들 것 (사람 결정 B 그대로)
1. **선택지 카드 누르기** → 고른 수로: 초안 문장(그 수의 AI 캐시 초안 또는 기존 초안 — 새 AI 호출을 만들지 말 것, 없으면 그 수의 기존 초안), 위험 %, 곡선 끝점, 손님 반응 막대, 칩이 모두 다시 계산. 시안처럼 초안이 타이핑되듯 들어가는 효과는 선택(짧게). 환불 카드 → "Refund done · Simulated" 상태 (실제 환불 없음). 막힌 수(서연의 부분 환불) 회색·누를 수 없음(`aria-disabled`).
2. **칩**: 빠진 것 "Missing: … + Add" → 문장을 답장 끝에 넣고 바로 다시 계산. 나쁜 것(blame·vague) "! … Remove" → 그 문장 삭제. 넣은 뒤 한국어 미리보기는 "Translated to Korean when you send." (시안 `autoTr`)로 바뀐다 — 번역은 Send 때 기존 경로.
3. **Details ⌄**: 칩마다 기여한 %p(`replyFeatureEffects`)와 해당 문장, 역번역(영어), 검사 3개, "PayPal data only: refund" 한 줄.
4. **Show history**: 시안처럼 날짜·사건·빨간 "Before DisputeLess" 태그로 펼침 — 실제 시드·샌드박스 사건만.
5. **왼쪽 목록**: 지호 → 짧은 카드 한 장 "Offer 15% back ($7.20), she keeps it" + [Send offer] (금액·비율은 엔진 값, 승인 관문 그대로). "N orders · Missing tracking" → "Add tracking to N orders in PayPal" + [Add all N] (기존 추적 등록 경로·관문, 공개 모드 Simulated).
6. **"+$N just now"**: 액션이 끝나면 "이번 주" 카드에 N(엔진 `actionSavings`/`trackingSavings`) — 서버 데이터는 바꾸지 않고 화면 상태로만 더한다(새로고침하면 원래 값; 시안과 같음).
7. **상품 칩 필터**: 누르면 그 상품 항목만 목록에. 맨 위 머리글(위쪽 막대 + 상품 칩 줄)은 스크롤해도 붙어 있게 (sticky).
