> **가장 중요한 규칙 (사람 결정 2026-11-12 09:25, DECISIONS)**
> 1. **시안 파일의 `<helmet><style>` 블록과 인라인 style을 그대로 복사한 전용 CSS**를 쓴다. 한 줄씩 다시 쓰거나 토큰으로 옮기지 않는다 — 값·선택자·keyframes를 그대로 둔다. 인라인 style(`style="…"`·`{{…St}}` 값)은 같은 값을 그 요소의 class 규칙이나 style로 옮긴다.
> 2. 화면 루트에 시안 루트 클래스의 기본값(시안 그대로: 15px, line-height 1.5, color #000, 배경 #FFF, 글꼴 등)을 둔다. **globals.css의 body 16px·#3F4144가 이 화면 안으로 상속되지 않게** 한다 (루트에서 다시 정하기). 다른 화면(/products 등)은 바뀌지 않게 한다.
> 3. **데이터 자리만** 엔진·실제 값으로 바꿔 끼운다. 시안과 다르게 두는 것은 DECISIONS 11/11 22:55 예외 목록과 v2.15 이후 결정(Simulated 표시, Assumption·Demo data 배지, 약속 금지, 통관번호 가림, 탭 없음, 진입점 등)뿐이다.
> 4. **동작은 바꾸지 않는다**: T102–T106의 상태·서버 액션·관문·Simulated·시험이 그대로 통과해야 한다. 옛 CSS 규칙은 새 CSS와 충돌하면 지운다 (안 쓰는 규칙은 지워도 된다). 정적 시험이 옛 클래스 이름·값을 고정해 깨지면, 시안 값으로 기대를 바꾸고 보고서에 이유를 적는다 (동작 시험은 바꾸지 않는다).
> 5. 실제 AI·PayPal 호출 금지, 개발 서버 금지, `.env` 읽기 금지. `_server/send.ts`·`mode.ts`·`activity.ts` 무변경.
> 6. 13:00에 화면을 고정한다. **12:15까지 보고**한다. 모자라면 화면 위쪽(먼저 보이는 곳)부터 하고 남은 곳을 보고서에 적는다.
