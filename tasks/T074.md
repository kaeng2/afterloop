## 바꾸는 것 (화면에 보이는 이름만)
- `config/copy.en.json`·`config/copy.ko.json`의 값에서 화면에 보이는 "AfterLoop"을 "DisputeLess"로: `nav.appName`(로고 글자·브라우저 탭 제목 — `layout.tsx`가 이 키를 읽는다), `shell.drawer.note`, `case.send.error.notOnScreen`, `case.routine.*` 등 값에 "AfterLoop"이 든 모든 키. 키 이름은 바꾸지 않는다.
- 화면 코드에 "AfterLoop" 글자가 직접 쓰인 곳이 있으면 문구 키로 옮긴다 (지금 확인으로는 없다 — 주석 제외).
- 이 이름을 단언하던 단위 테스트(`app-t064-activity`, `app-today`, `app-t061` 등)는 새 이름으로, 가능하면 **문구 파일에서 읽은 값으로** 단언하게 고친다 (이름이 또 바뀌어도 테스트가 따라가게). 다른 기대값은 바꾸지 않는다.

## 바꾸지 않는 것 (사람 결정)
- 코드 안 변수·함수·폴더·패키지 이름(`package.json`의 name 포함), 주석, CSS 주석, 요청 번호 꼴(`afterloop-track-…` 등 PayPal에 이미 쓴 값), 환경변수 이름(`AFTERLOOP_*`), 저장소 이름.
- **`src/ai/prompts/`의 시스템 프롬프트 글자 "AfterLoop"는 고치지 않는다** — 프롬프트가 바뀌면 AI 캐시(`data/ai-cache/llm-cache.json`) 키가 모두 바뀌어 공개 데모가 실제 AI를 다시 부른다. 프롬프트는 화면에 보이지 않는다.
