## 수정 가능 폴더
- `src/app/products/**`, `config/copy.*.json`(`product.` 키), `tests/unit/app-product*.test.ts`
- `package.json`은 고치지 않는다 (이미 있다)

## 만들 것
- T062의 왼쪽 임시 목록을 AG Grid Community 표로 바꾼다. 열: **Product · Left · As-is → With fixes** (마지막 열은 두 값을 함께, 예 "$216 → $44". 모호하지 않게). 행 데이터는 T062의 보기용 함수 결과를 그대로.
- 처방을 토글하면 With fixes 값이 바뀐 셀이 **깜빡인다** (AG Grid 셀 변경 깜빡임 기능. 행 ID는 sku로 고정해 표 전체를 다시 그리지 않고 바뀐 셀만 깜빡이게).
- 행을 누르면 그 상품을 고른다 (주소 `?sku=`). 키보드로도.
- 모양: AG Grid 테마를 우리 디자인 변수로 맞춘다 (강조색 하나, 기본 파랑 쓰지 않기, 테두리 옅게, 글자는 지금 글꼴, 숫자 폭 일정). 정렬·필터 메뉴는 숨긴다 (4행 표).
- 서버 렌더에서 깨지지 않게 (클라이언트 컴포넌트).
