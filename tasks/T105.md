> 1. 차이 목록 번호: F3-N = 파일의 ② 절 N번, F4-N = ③ 절 N번. 각 줄에 시안 줄(M:… = Desk.dc.html)·구현 파일:줄(DM = desk-model, CSS = case.css 등)·근거가 있다.

> 4. 실제 AI·PayPal 호출 금지, 개발 서버 금지, `.env` 읽기 금지.

## 고칠 것
1. **F3-10** 곡선 x 배치: 시안 M:727-735 `xStep = 640/12` 고정, `x = i*xStep + 8`, 초안 점 = 마지막 사건 + xStep, 오른쪽 1/3은 Send 뒤 단계용 빈칸. 점·ping이 오른쪽 눈금 글자와 겹치지 않게.
2. **F3-11** Send 뒤: 단계 점을 `xStep*0.8`씩 오른쪽에 덧붙이고 기존 점 위치는 고정 (재배치·점프 없음).
3. **F3-17** 초안 점·ping 이동: 시안처럼 즉시 (점·ping에 transition 없음. polyline 색 transition은 시안 값 그대로).
4. **F3-13** 곡선과 점 줄 색 규칙을 시안 `whoCol` 하나로: buyer #3F4144, bad(판매자 잘못) #C4321F, sys #9AA0A6. 곡선 구간과 사건 기록 점이 같은 규칙. 시안에 없는 seller 파랑·검정 없앤다.
5. **F3-22 · F4-32** 빈 답장(Clear 등으로 글이 빔) = 무응답 예측: 엔진 빈 글 예측값, 큰 위험 아래 글 "if no reply by {date}"(시안 문구, copy 새 키), "N% → M%"(fromTo) 숨김, 답장 칸 위험 알약도 같은 무응답 값. 글이 생기면 지금처럼.
