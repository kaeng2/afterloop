> **가장 중요한 규칙**
> 1. 화면이 실제로 부르는 입력과 **똑같은 입력**으로 부른다 — 같은 캐시 키가 나와야 한다. 기본 폼 값은 `config/listing.en.json`·`config/listing.ko.json`의 init(상품명·설명) 두 벌 (언어마다 폼 기본값이 다르므로).
> 2. 실제 AI 호출은 컨트롤 타워가 스크립트를 돌릴 때만. 이 태스크의 시험은 가짜 LLM. `.env` 읽지 않음.

## 수정 가능 폴더
- `scripts/ai-cache/**`, `tests/unit/` 스크립트 시험

## 만들 것
- `buildAiCache`가 분쟁 사례에 더해 `/listing` 고칠 문구를 en·ko 기본값 두 벌로 한 번씩 부르게 한다 (화면 서버 액션과 같은 함수·같은 입력 모양 — 가능하면 `src/app/listing/fixes.ts`의 함수를 그대로 import).
- 결과 요약 출력에 "listing fixes en/ko: 칸별 ok 수" 한 줄 (글 내용·키 출력 금지).
- 시험: 가짜 LLM이 받은 user 문자열이 화면 서버 액션이 만드는 문자열과 같다 (en·ko 둘 다).
