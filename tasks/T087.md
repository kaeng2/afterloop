> **가장 중요한 규칙**
> 1. **화면은 계산하지 않는다.** 숫자는 엔진(`createListingSim`·`checkListing`·`listingFixGains`·`detectListingFeatures`) 결과를 옮기기만. 표기(%, $)만 화면이 한다.
> 2. **진행 표시 = 실제로 끝낸 횟수.** 한 프레임(`requestAnimationFrame`)에 `progressChunkRuns`회씩 `step`. setInterval로 늘이거나 가짜로 세지 않는다. 분석 단계 4줄도 실제 단계(입력칸 판정 → 판매 기간 → 유형별 가정 확률 → 시뮬레이션 n/500)에 맞춘다.
> 3. 색은 우리 강조색 (PayPal 파랑 #002991·#0066F5·#60CDFF·#0070E0·#003087 금지 — 시안의 파랑 그라데이션도 강조색으로). PayPal 로고 없음, 왼쪽 메뉴 "PayPal payments"는 아이콘 없이 글자만.
> 4. 실제 AI·PayPal 호출 금지 (가짜로 시험). 개발 서버 금지.

## 만들 것
1. **경로 `/listing`** — `/intro`처럼 위쪽 앱 막대·Today 읽기 없이 (route group 밖). 쇼핑몰 관리자 껍데기(왼쪽 메뉴·검색창·가게 이름 **Fernwood Knits**)는 고정 데모, 동작하는 것은 이 장면의 흐름뿐. 맨 위 "Demo mock" 띠는 `/intro`와 같은 방식.
2. **흐름 (시안 그대로)**: 상품 추가 폼(사진 4장·상품명·가격·수량·설명·사이즈·배송·반품·판매 시작/끝 날짜, 기본값은 시안 그대로) → **Publish product** → 점검 모달(진행 → 결과: 주문당 분쟁 확률·예상 건수·점 그림 200개·예상 손실(P10–P90)·유형별 상위 3개 확률과 이유·Black Friday 배송 안내·고칠 점 상위 4개 "chance −x pts") → **See details and fix** → 왼쪽 입력칸마다 Missing 표시 + 고칠 점별 **AI 문구 넣기** 버튼 / 오른쪽 결과판(이전 대비, 유형별 막대, 체크리스트) → 글이 바뀌면 "Changed — recalculate" → **Recalculate**(같은 진행 규칙) → 확률 내려감 → **Publish product** → 완료 카드(확률·손실·건수 이전→이후). "Publish anyway"·"Replay this scene"도 시안대로.
3. **AI 문구**: 서버 액션이 `draftListingFixes({ productTitle, productDescription: Publish 시점 설명 })`를 **한 번** 부르고(데모 모드 AI 캐시·횟수 제한 그대로), `ok:false`인 칸은 넣기 버튼을 숨긴다. 넣은 글은 그 입력칸 끝에 붙고 `[__]` 자리표시자는 눈에 띄게. 넣은 뒤 판정은 엔진 `detectListingFeatures`가 한다 (AI가 아님).
4. **배지**: 숫자 옆 "≈ Assumption" (확률·건수·손실·유형별 %·chance −x pts). 기준 줄 "Data"는 **"Assumed rates (planning draft) · 500 simulations"** + Assumption (DECISIONS "Scene 3 정직성" ①). 고칠 문구 옆 "AI suggests".
5. **문구 정직성** (DECISIONS ①~③): 분석 단계 3번 "Applying assumed dispute rates by type", 계산 방법 설명은 params 값($15 수수료, 환불 50% 가정)을 문구 자리표시자로 넣어 쓴다(숫자를 문구 파일에 박지 않음), Black Friday 배송 안내는 숫자 없는 문장.
6. **`POST /api/listing-check`**: zod 입력(`ListingCheckInput`) → `checkListing` 결과 JSON. PayPal·AI 호출 없음. 잘못된 입력 400. 같은 입력이면 화면 모달 결과와 같은 숫자 (시험).
7. **메뉴**: 위쪽 막대 "Black Friday rehearsal" → `/listing`. 기존 Products 화면(AG Grid)은 지우지 않고 위쪽 막대에 "Products" 링크로 남긴다.
8. **언어**: T081의 언어 값(쿠키·`?lang`)으로 `listing.en/ko` 문구를 고른다. ko 값은 시안 `LI.ko`를 우선 (결정과 어긋나는 것 제외). AI 문구는 영어 그대로.
9. 1920×1080·1440 폭에서 모달과 상세가 시안 배치대로, 390 폭에서 가로 넘침 없음.
