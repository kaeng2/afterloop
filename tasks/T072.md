## 만들 것
1. **처음 상태 = 처방 모두 꺼짐.** 새로고침·처음 열기 모두 꺼짐. 큰 숫자는 as-is 하나 + "Turn on a fix to see it change." (T062 지시서 그대로). 상품을 바꿔도 지금 켠 상태를 유지하는 것은 그대로.
2. **처방 카드 숫자**: 지금의 두 값 나란히("Turn on: $216 → $170") 대신 엔진 `fixSavings(input)`의 `savingCents`를 달러 반올림으로 한 숫자:
   - 꺼진 카드: "could save **$X**" (켜면 줄어드는 금액)
   - 켜진 카드: "saving **$X**" (끄면 늘어나는 금액) — 문구 키로
   - 화면은 계산하지 않는다 (빼기 없음 — 엔진 값을 옮기기만). 토글할 때마다 엔진 값으로 다시.
3. 왼쪽 AG Grid 표의 With fixes 값·깜빡임은 그대로 동작해야 한다.
