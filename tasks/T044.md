## 만들 것

### 1. `followUpDate` (`src/engine/followup.ts`, 타입 `FollowUpDateFn`) — AC30이 정본
- 날짜 = `now`의 UTC 날짜 + `followUpDays`
- 그 날짜가 `disputeDueDate`의 UTC 날짜보다 **늦으면** 기한 하루 전으로 당긴다. 같은 날이면 당기지 않는다
- 당긴 날짜가 `now`의 날짜보다 앞서면 `now`의 날짜
- `disputeDueDate`가 빈 문자열이면 당기지 않는다
- `policy`를 안 주면 `config/rules.json`의 `reply`를 읽는다 (작은 zod 스키마로 검증: `followUpDays`는 1 이상의 정수. `PolicyConfigSchema`는 건드리지 않는다)
- 결과는 `YYYY-MM-DD`. `Date.now()`·시간대(로컬)를 쓰지 않는다. 잘못된 입력(`now`가 날짜가 아님, `disputeDueDate`가 비어 있지 않은데 날짜가 아님)은 예외
- 이 날짜가 답장의 `⟦DATE_1⟧` 값이 된다. 사실값 묶음을 만드는 도우미도 둔다: `replyFacts(input, policy?) → FactToken[]` (지금은 `{ token: '⟦DATE_1⟧', kind: 'DATE', value: <위 날짜> }` 1개. 토큰 글자는 `src/ai/tokens.ts`가 쓰는 꼴과 **글자까지 같아야** 한다 — 그 파일을 읽어 확인하되 import하지는 않는다. 엔진은 ai 레인 코드에 기대지 않는다)

### 2. `buildEscalationSignals` (`src/engine/signals.ts`) — SPEC 7장의 신호를 데이터에서 만든다
```ts
type SignalInput = {
  buyerMessages: { text: string; at: string }[]; // 구매자 글 (이전 문의 + 분쟁 접수 글). at은 ISO 날짜 또는 날짜시각. 순서는 보장되지 않는다
  sellerReplies: { at: string }[];               // 판매자가 답한 시각들
  now: string;
  disputeDueDate: string;                        // '' = 기한 없음
  angryTone: boolean | null;                     // LLM 판별 결과 (T043). 없으면 null
};
buildEscalationSignals(input: SignalInput): EscalationSignals
```
- `mentionsCardCompany`: 구매자 글 어디에든 은행·카드사·chargeback 언급이 있으면 참. 낱말 목록은 이름 붙인 상수로 한곳에 (SPEC 7장: "카드사", "이의제기" 포함. 영어 `chargeback`, `card company`, `credit card company`, `my bank`, `dispute with my card`, 일본어 `カード会社`, `チャージバック`, 독일어 `Kreditkartenunternehmen`, `Rückbuchung`, `meine Bank` 정도). 영어는 대소문자 무시. 판매자 답장 뒤에도 유지된다 (SPEC 7장의 "답장 후 3")
- `secondMessageUnanswered`: 판매자가 답하지 않은 구매자 글이 **연달아 2건 이상** 있고, 마지막 구매자 글 뒤에 판매자 답장이 없을 때 참
- `unansweredOver24h`: 마지막 구매자 글 뒤에 판매자 답장이 없고, 그 글에서 `now`까지 24시간이 **넘었을** 때 참
- 판매자가 마지막 구매자 글 **뒤에** 답했으면: 위 두 신호는 거짓, `angryTone`은 `null` (SPEC 7장 "판매자가 답장한 뒤에는 구매자의 다음 메시지가 올 때까지 0"). 그 뒤 구매자가 다시 글을 쓰면 `angryTone`은 입력값 그대로
- `hoursToDue`: (`disputeDueDate` − `now`) 시간. 지난 기한은 음수. **기한이 없으면** 이름 붙인 큰 유한 상수(예: `HOURS_TO_DUE_NONE`)를 넣는다 — `escalationRisk`가 유한한 수만 받고, SPEC 7장이 "응답 기한이 없는 분쟁은 기한 점수 0"이라고 정한다. 상수는 export한다
- 날짜만 있는 `at`(`2026-11-02`)은 그날 00:00 UTC로 본다. 같은 시각의 구매자 글과 판매자 답장은 "답장이 뒤"로 보지 않는다 (답하지 않은 것으로 본다 — 막는 쪽)
- 구매자 글이 없으면: 언급·무응답 모두 거짓, `angryTone`은 `null`
- `Date.now()`를 쓰지 않는다. 같은 입력이면 같은 결과
