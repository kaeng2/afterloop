## 시안에서 따르는 값 (사람이 시안 코드에서 읽은 값)
- **배치**: 전체 폭. 가운데 고정 폭 상자 제거. 위쪽 막대 전체 폭. 왼쪽 목록은 화면 왼쪽 끝에 붙고 위아래 전체 높이(위쪽 막대 아래부터 화면 끝까지, 목록이 길면 그 칸만 스크롤), 오른쪽 상세가 남은 폭을 모두 쓴다 (상세 안 글 줄은 읽기 좋은 최대 폭 — T061에서 정한 값 유지). 목록 칸 폭은 시안 값(약 340px)에 가깝게. **"360px 넘는 고정 폭 금지" 검사는 유지** — 목록 칸은 340px 이하로.
- **배경**: 목록 영역 `#F1EFEA`, 상세 영역 `#FFFFFF`. 위쪽 막대 흰색 + 아래 1px `#E4E6E9`.
- **글꼴**: Figtree + Noto Sans KR (Google Fonts, `next/font/google`로 — 빌드 때 받아서 자체 제공. `@import url(...)` 쓰지 않는다). 본문 색 `#3F4144`, 제목 `#000000`. 한국어 글은 Noto Sans KR이 쓰이게 (글꼴 묶음 순서 또는 `lang="ko"` 부분).
- **카드**: 테두리 2px `#E4E6E9`, 모서리 16~24px. 알약(탭·배지·버튼)은 완전히 둥글게.
- **목록 항목**: 왼쪽에 **위험 등급 색 점**, 오른쪽에 **상태 알약 배지**(연한 배경):
  - High = 연분홍 배경 + 진한 빨강 글자
  - Watch = `#FFF3D6` 배경 + `#6B4700` 글자
  - 중립 = `#ECEEF0` 배경 + `#3F4144` 글자
  - **고른 항목 = 흰 카드 + 그림자 `rgba(0,0,0,0.14) 4px 4px 28px 6px`** (이 그림자 하나만 허용 — 변수 하나로 두고 디자인 테스트는 "그림자는 이 변수 하나만"으로 바꾼다)
- **로고**: 28px 원형 마크(고리 모양 아이콘, 인라인 SVG, 강조색) + 굵은 "AfterLoop".
- 새 색 값은 모두 `globals.css`의 변수로 (`--color-list-bg`, `--color-divider`, `--color-text-body`, `--color-heading`, 배지 색 변수 등). 어두운 모드 값도 같은 이름으로 정한다 (시안에 없으니 어울리게. 보고서에 적는다).

## 고칠 것
1. **점 = 위험 등급, 배지 = 상태**로 구분한다:
   - 서연: 빨강 점 + 배지 "High" (분홍)
   - 추적 2건: 노랑 점 + 배지 "Watch"
   - 지호: 점은 엔진 위험 등급 색 + 배지 회색 **"Waiting approval"** (초록 "Low" 배지 대신)
   - 가디건(Prevent): 배지 회색 "Prevent"
   - Mike: 회색 점 + 배지 회색 **"Skipped"** (초록 "Low" 대신)
   - 배지 글자는 문구 키, 고르는 기준은 엔진 판정·묶음 (화면이 판단을 지어내지 않는다)
2. **추적 표**: 회색 줄(O02·O13, "In dispute — excluded")도 같은 열 격자에 맞춘다 (T061이 고쳤으면 확인만).
3. **"Add both to PayPal" 버튼** (추적 상세): `tasks/T063.md`의 "만들 것"·안전 규칙대로 — 대상은 분쟁 없는 미등록 주문(O05·O07)만, 서버 액션이 `registerTrackers`를 `liveGateFromEnv(process.env, …)` 게이트로 부른다. 스위치 꺼짐 = dry run → 결과 줄 "Simulated · nothing was sent to PayPal". 켜짐(녹화 때) = "✓ 2 trackers added · Orders tracking API · 201" + 행마다 추적번호. 실패 = 행마다 이유. 분쟁 걸린 주문은 버튼 대상에 없다. (T064 기록기가 이미 있으면 그것을 지나게. 없으면 T064가 연결한다)
4. **Prevent 비율**: 화면 코드의 `pickPrevent`가 아직 있으면 엔진 `pickPreventProduct`(T066)로 바꾼다.
