## 고칠 것
1. `config/copy.ko.json`의 `case.reply.editSub`(그리고 T107이 바꾼 이름 규칙 키 전부: `case.reaction.moodNext` 등)에 en과 같은 자리표시자를 넣는다 (시안 DI.ko 문구를 쓰되 `{{name}}` 포함 — 예: "{{name}} 님의 반응이 입력하는 대로 바뀌어요" 꼴. 이름이 없을 때 키(`…Unknown`)는 자리표시자 없이).
2. React #310의 원인을 찾아 고친다 (ko일 때만 hook 수가 달라지는 컴포넌트 — 예: `copy.ts currentLocale()`, `conversation.tsx koScreen`, 언어에 따라 일찍 return하는 곳). /products에서도 나므로 공용(`_shared`·top-bar·layout) 쪽을 먼저 본다.
3. **재발 방지 시험**: en·ko 두 문구 파일에서 같은 키의 자리표시자 집합이 같다 (모든 키). ko로 Desk·지호·/products·/listing·/intro를 정적 렌더할 때 예외가 없다.
