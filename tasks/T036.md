## 수정 가능 폴더
- `seed/` (`seed/data.ts`가 원본, `seed/*.json`은 `npm run seed`로 다시 만든다. `seed/README.md` 포함)
- `tests/unit/seed.test.ts`

이 밖은 수정하지 않는다. `tests/acceptance/`는 실행만 한다.

## 고칠 것
1. **서연(B01)의 2026-11-09 문의 1건**의 `original`을 아래 문장으로 바꾼다 (한 글자도 다르지 않게. 첫 문장은 지금과 같다):

   ```
   벌써 3주째인데 아직도 안 왔어요. 배송 조회를 해 봐도 며칠째 같은 단계에서 멈춰 있고, 판매자에게 메시지를 보냈는데 답도 없어요. 선물하려고 산 스웨터라 더 기다리기 어렵습니다. 이번 주 안에 연락 없으면 카드사에 이의제기할게요.
   ```

2. 같은 건의 `english`를 위 문장 전체의 번역으로 바꾼다:

   ```
   It's been 3 weeks and it still hasn't arrived. Tracking has been stuck at the same step for days, and I messaged the seller but got no reply. I bought this sweater as a gift, so I can't wait much longer. If I don't hear back this week, I'll file a dispute with my card company.
   ```

3. 그 밖의 값(`date`, `buyerId`, `signal`, `isDemo`, 문의 건수 31, 구매자별 건수)은 그대로다. **지호(B02)·buyer_m(B04)의 문의는 바꾸지 않는다** (그 문의들은 분쟁 전에 온 다른 글이다).
4. `npm run seed`로 `seed/*.json`을 다시 만든다. `seed/inquiries.json`에서 바뀌는 것은 이 1건의 두 칸뿐이어야 한다 (`git diff --stat`로 확인. 다른 파일이 바뀌면 멈추고 보고).
5. `tests/unit/seed.test.ts`의 기대 문장(72행 근처)과 `seed/README.md`의 관련 설명을 새 문장에 맞춘다.
