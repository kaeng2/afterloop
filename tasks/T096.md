> **가장 중요한 규칙**: 링크·탭만 없앤다. 화면(`/products`, `/listing`)과 기능은 지우지 않는다. 숫자·관문·데모 모드 무변경. 실제 AI·PayPal 호출 금지, 개발 서버 금지.

## 수정 가능 폴더
- `src/app/**` (send.ts 관문·mode.ts·activity.ts 무변경), `config/copy.*.json`(en=ko), `config/listing.*.json`(메뉴 동작만), `tests/unit/`

## 만들 것
1. Desk 위쪽 막대: 탭(Today / Black Friday rehearsal / Products) 제거. 왼쪽 = 로고·"for PayPal sellers"·날짜만. 오른쪽 = 공개 데모 표시(작은 회색)·PayPal activity·EN/KO·판매자 (작게).
2. Desk·/intro·/products 어디에도 `/listing` 링크 없음. Desk 왼쪽 "Stock left could cost … →" 등 `/products` 링크 제거 (시안에 없음). /intro의 버튼은 지금처럼 `/`(서연)로만.
3. `/products`·`/listing`은 그대로 주소로 들어갈 수 있다 (`/products`에서 Desk로 돌아가는 로고 링크는 남겨도 된다).
4. `/listing` 왼쪽 메뉴 "DisputeLess" 줄은 눌러도 이동하지 않는다 (`type="button"`, 핸들러 없음, `aria-disabled`).
5. 지금 Today 탭 숫자(Today (N))가 없어지므로 그것을 읽던 Suspense 막대(T084)가 필요 없어지면 정리 — 단 위쪽 막대가 Today 데이터를 읽지 않게 되면 레이아웃 시험(T084·T079)을 뜻에 맞게 고친다.
