## 만들 것
- `draftListingFixes(input: ListingFixDraftInput, deps: { llm: LlmCaller }): Promise<ListingFixDrafts>` — AI **한 번** 호출로 6개(size·color·ship·customs·bf·ret)를 영어로 받는다 (zod 스키마, 예외 던지지 않음, 로그 없음).
  - 입력은 상품명과 Publish 시점의 설명뿐 (같은 입력 = 같은 캐시 키). 설명은 신뢰하지 않는 입력 — 주입 방어·개인정보 가리기는 T020 방식.
  - 칸별 내용 (시안 `LI.en.fixes`의 주제를 따르되 구체 값은 `[__]`): size = 사이즈별 실측 칸(chest·length·sleeve, `[__] cm`)과 핏 안내 / color = 색 이름(설명에 있는 색만)과 화면·조명에 따라 달라 보일 수 있다는 color note / ship = 발송 기간 `[__]` 영업일과 모든 주문에 tracking / customs = 해외 구매자에게 checkout에서 customs ID(또는 tax ID) 입력 요청 (나라 예시는 써도 됨) / bf = Black Friday·peak 시즌에 배송이 더 걸릴 수 있음 (날짜 약속 없이) / ret = 반품 조건 `[__]`일, 상태 조건 (무료·환불 시기 약속 없이).
  - 칸별 판정: 숫자 없음, 약속 검사, 길이 상한(줄 수·글자 수 — 보고서에), 자기 정규식에 걸림. 실패한 칸은 `{ ok:false, reason: <고정 코드> }`.
- 호출 수 고정: 1회. 다시 묻지 않는다.
