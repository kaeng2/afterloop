> 1. 곡선 SVG만 고친다 (`src/app/cases/view/risk-curve.tsx`, `src/app/cases/desk-model.ts`의 곡선 좌표 부분, 곡선 CSS). 숫자(점 값)는 엔진 그대로. T105의 규칙(x = i·xStep + 8 같은 시안 비율, 초안 점 = 마지막 사건 + xStep, Send 뒤 단계 점 xStep·0.8씩 덧붙이고 앞 점 고정, whoCol 색, 점·ping transition 없음, 빈 답장 무응답 예측)은 그대로 — 폭만 실제 px로.

## 고칠 것
- 컨테이너 폭을 ResizeObserver로 재서 **viewBox 폭 = 실제 px 폭**으로 그린다. x 좌표는 시안 비율 그대로 (xStep = 폭/12, 오른쪽 1/3은 Send 뒤 단계용으로 비움). `preserveAspectRatio="none"`은 쓰지 않는다. 세로(높이)도 실제 px — 늘림 없음.
- 선·점선(곡선 polyline, 초안 점선, 눈금선)은 `vector-effect="non-scaling-stroke"`로 두께 고정. 점 r 4.5·5, ping r 7→20 (keyframes `ping`)은 px 그대로.
- 100%·50% 눈금 글자와 초안 점·ping이 겹치지 않게 (넓은 폭·좁은 폭 모두).
- 처음 그릴 때(서버 렌더) 폭을 모르면 시안 기준 640으로 그리고, 폭을 재면 바로 다시 그린다 — 깜빡임 없이 (useLayoutEffect 등).
- `reports/design-match/inventory.md` 또는 예외 목록 문서에 "시안 SVG 늘림 버그 수정 = 의도적 개선 (사람 결정 11/12 10:55)" 한 줄 (inventory의 곡선 viewBox/preserveAspectRatio 행).
