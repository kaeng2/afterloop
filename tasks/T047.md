> **가장 중요한 규칙**
> 1. **화면은 계산하지 않는다.** 이 작업이 만드는 금액 표시 함수는 표기만 바꾼다 (센트 → 글자). 새 금액·점수를 만들지 않는다.
> 2. PayPal·LLM 호출은 서버 코드에서만 한다. 비밀값이 브라우저 묶음에 들어가면 안 된다.
> 3. `.env`를 찾거나 만들지 않는다. 실제 PayPal·LLM 호출을 하지 않는다 (가짜 클라이언트로만 시험).
> 4. **연습용 분쟁과 시연 제외 분쟁(`demoExcluded`)은 어느 화면에도 내지 않는다.** 이 작업의 읽기 함수가 한 곳에서 걸러 낸다. 이전 분쟁 수에도 세지 않는다.
> 5. 이 작업은 PayPal에 POST를 보내는 코드를 만들지 않는다 (조회만).

## 만들 것
### 1. 레이아웃 (`src/app/layout.tsx`, `globals.css`, `page.tsx`)
- 머리글과 메뉴 5개 (Today / Product check / At-risk orders / Inbox / Case는 메뉴에 없고 Inbox에서 들어간다). 글자는 `nav.*` 문구.
- create-next-app 예시 화면을 지운다. `page.tsx`는 메뉴만 있는 임시 화면이다 (T014가 바꾼다).

### 2. 문구 읽기 (`src/app/_shared/copy.ts`)
- `t(key, params?)`: `config/copy.en.json`에서 읽고 `{{이름}}`을 채운다. 없는 키면 예외 (빈 글자를 내지 않는다).
- 화면은 영어다. `copy.ko.json`은 키만 똑같이 맞춘다.

### 3. 금액 표시 (`src/app/_shared/money.ts`) — **반올림은 여기 한 곳에서만**
- `toDollarsRounded(cents)` → `"$74"`. 달러로 반올림한 표기 (사사오입. 7400 → `$74`, 3680 → `$37`, 21619 → `$216`). 정수 연산만 쓴다.
- `toDollarsCents(cents)` → `"$72.00"`. `centsToDisplay`를 그대로 부른다 (분쟁 금액처럼 정확한 금액용).
- 다른 화면 지시서는 이 두 함수만 쓴다. 화면 코드에서 `/ 100`이나 `toFixed`를 쓰지 않는다. 엔진이 준 센트 값은 보기용 값 묶음에 그대로 함께 둔다 (SPEC 2장 "엔진 값은 센트 그대로 두고 화면 표시만 반올림").

### 4. 배지 (`src/app/_shared/badges.tsx`)
`Demo data`, `Assumption`, `AI suggests`(보라), `Code decides`(회색), 위험 구간(Low / Watch / High). 글자는 `badge.*` 문구. `cached` 배지는 T019가 생길 때 더한다 (지금 만들지 않는다).

### 5. 서버 도구 (`src/app/_server/paypal.ts`, `llm.ts`)
- `getPayPalClient()`: 환경 변수로 `createPayPalClient`를 만든다. `getLlm()`: `createLlmCaller`를 만든다. 둘 다 서버에서만 불린다.
- 환경 변수가 없으면 예외를 화면까지 올리지 않고 "쓸 수 없음"을 돌려준다 (화면은 `common.paypalUnavailable`·"AI unavailable — showing rules only" 문구를 보인다).

### 6. 실제 분쟁 읽기 (`src/app/_server/disputes.ts`) — S5·S4·S1이 함께 쓴다
`loadDemoDisputes(deps?)` → 분쟁마다 아래 묶음. `deps`로 가짜 PayPal 클라이언트·가짜 LLM을 넣을 수 있다.

읽는 순서:
1. `listDisputes` → **연습용·시연 제외 분쟁을 뺀다** (T046의 표시) → 연결 표에 있는데 목록에 없는 분쟁은 `getDispute`로 직접 읽는다 (방금 접수된 분쟁은 목록에 늦게 나온다, SPEC 9-4).
2. 이전 미수령 분쟁 수는 **뺀 뒤의 목록**으로 `countPriorInrDisputes`를 부른다 (안 빼면 서연이 1로 나온다).
3. LLM은 규칙이 정하지 못한 보드에만 불린다. 화면에 쓰지 않는 보드를 위해 부르지 않는다.
4. 돌려주는 값에 구매자 이메일·주소·`payer_id`·응답 원문이 없다.
5. 같은 요청 안에서 두 번 불려도 PayPal을 한 번만 읽는다 (S5는 화면과 답장 칸이 따로 부른다).

순수 함수로 떼어 시험할 것 (`src/app/_shared/`): `withoutDemoExcluded(disputes, links)`, `pickBoard(loaded)` (= `boardDemo ?? boardReal`).

## 보완 (재시도 1회, 사람의 스크린샷 확인 요청 2026-11-10)
사람이 병합 전에 스크린샷으로 확인한다. 아래 네 가지를 고친다. 수정 가능 폴더는 본문과 같다 (`src/app/` 중 이 작업 몫, `config/copy.*.json`, `tests/unit/app-*.test.ts`). 보고는 `reports/T047-impl.md`에 "보완" 절을 덧붙인다.

1. **`cached` 배지 추가**: 배지는 5종이다 — `AI suggests` / `Code decides` / `Demo data` / `Assumption` / **`cached`** (SPEC 9-4장: 거래 조회는 몇 시간 늦게 반영될 수 있어 캐시 값에 'cached' 배지). 위험 구간 배지 3종은 그대로 둔다. 문구 키 `badge.cached` (두 문구 파일 모두), 색은 다른 배지와 구분되게, 밝은·어두운 모드 모두.
2. **배지를 한눈에 보는 화면**: `src/app/preview/badges/page.tsx` (주소 `/preview/badges`). 배지 5종 + 위험 구간 3종을 이름과 함께 한 줄씩 보여 준다 (언제 쓰는 배지인지 한 줄 설명. 문구는 문구 파일에서). 메뉴에는 넣지 않는다. 이 화면은 스크린샷 확인용이고 데이터를 읽지 않는다 (PayPal·LLM·시드 호출 없음).
