## 배치 (한 열, 위에서 아래로)
1. **머리글**: "Case PP-R-GMS-10197661 · Wool Sweater $72 · Waiting for your reply" (상품은 시드 상품 이름의 쉼표 앞 부분, 금액은 분쟁 금액 달러 반올림 — 둘 다 데이터에서) / "김서연 Seo-yeon Kim · writes in Korean" / 오른쪽 위 작은 위험 배지 (지금 그대로).
2. **비교 카드 — 가로 전체 폭** (시안의 파란 AI 상자 자리): 지금 내용 그대로("PayPal data only · Full refund ~~$74~~ incl. $2 of your time → With carrier data · Reply **$37**", Assumption, 오른쪽 Demo data). **카드 안 아래쪽에 한 줄** "It's not lost — it's held at Korean customs, waiting for one number." + Code decides 배지 (A1→A2 작은 글씨는 있어도 된다). **따로 있던 회색 요약 상자는 없앤다.**
3. **대화 말풍선**: 지금 그대로 (한국어 크게 + 영어 작게, 가운데 "Oct 30 · Carrier: Customs hold – recipient customs ID missing" + Demo data, 강조·밑줄 그대로). 폭은 상세 폭 안에서 시안처럼 말풍선이 내용 폭만큼.
4. **"Suggested reply covers" 칩 줄**: 제목 "Suggested reply covers:" + 알약 칩들 + AI suggests 배지. **"5 coaching tips ▸" 접기는 없앤다** (칩으로 대체). 칩 글자 안의 토큰은 실제 값으로 채워 보인다 ("Follow-up: Nov 17").
5. **답장 좌우 두 칸** (시안처럼 카드 두 개 나란히): 왼쪽 **"You write (English)"**, 오른쪽 **"Seo-yeon reads (Korean)"** (구매자 이름은 데이터에서. 대명사를 쓰지 않는다 — 성별 데이터가 없다). **두 칸 글씨 크기 같게 = 본문 크기**. 둘 다 AI suggests 배지. 역번역은 칸 아래 "Back-translation ▸"로 접기.
6. **맨 아래 한 줄**: 왼쪽에 ✓ Facts match · ✓ No new promises · ✓ Follow-up date 11월 17일 + "More checks ▸"(실패한 검사는 접혀 있어도 이 줄에 보인다 — 지금 규칙 그대로), 오른쪽 끝에 **[Send in Korean]**(강조색). "Simulated send — nothing goes to PayPal"(또는 "Live · PayPal sandbox") 표시는 **버튼 옆 작은 글씨**.

## 재시도 (컨트롤 타워, 2026-11-10 실제 스크린샷 확인 결과) — 앞 절보다 이 절이 맞다
`lane/ui` 커밋 `dde4d40`(T069 칩 병합 뒤)을 배포용 빌드 + 실제 AI로 1920×1080에서 찍었다 (아래 수치는 그 화면에서 잰 값).

1. **서연: [Send in Korean]이 1920×1080 화면 아래 끝에 걸려 잘린다** (버튼 윗변 약 y=1053, 화면 높이 1080 — 반드시 한 화면에 들어와야 한다). 세로로 **최소 90px**, 여유를 두고 120px 이상 줄인다. 내용은 빼지 말고 여백·배치로:
   - 비교 카드 높이(지금 약 200px): 두 숫자 칸과 요약 줄 사이 여백, 카드 위아래 안쪽 여백을 줄인다. "Expected loss" 머리 줄과 칸 이름표 사이 간격도.
   - "Conversation" 제목 줄을 없애거나 말풍선 줄과 합친다. 배송사 줄("Oct 30 · Carrier …")과 첫 말풍선 사이, 말풍선 사이 간격을 줄인다. 말풍선 안 아래쪽 "Dispute message · From PayPal" 꼬리 줄은 영어 번역 줄 끝에 같은 줄로 붙인다.
   - 칩 줄 위 구분선과 위아래 여백을 줄인다.
   - 답장 두 칸: 칸 안 위아래 여백과 "You write (English)" 머리 줄 높이를 줄인다. 칸 높이는 내용 높이(빈 아래 공간 없이).
   - "Back-translation to English ▸" 줄은 답장 칸 바로 아래 왼쪽, 맨 아래 검사 줄과 **같은 줄의 왼쪽 끝**으로 합쳐도 된다.
   - 맨 아래 한 줄이 한 줄을 넘지 않게.
   - 기준: AI 초안 길이가 지금(영어 8줄 안팎)일 때 버튼 아래 끝이 **약 1000px 이하**.
2. **지호: 분쟁 메시지 원문이 영어일 때 영어가 두 번 나온다** (원문 큰 글씨 + 같은 글의 "번역" 작은 글씨 + AI suggests). 원문 언어가 영어면 번역 줄과 그 AI suggests 배지를 숨기고 원문만 (판단은 데이터의 원문 언어·번역 결과로. 두 글이 같으면 번역 줄 숨김도 함께).
3. 지호 맨 아래 줄이 두 줄로 넘친다 ("Simulated send…" · [Send offer · $7] · [Send in Korean] · 안내 글). 안내 글("Send the offer first — …")은 [Send in Korean] 버튼 아래 작은 글씨로 내리거나, [Send in Korean]을 작은 글자 버튼으로 줄여 **주 버튼 [Send offer · $7]이 오른쪽 끝**에 오게.
4. 칩 날짜: 칩 안의 날짜는 **짧은 달 이름**("Follow-up: Nov 17")으로 보인다 — 칩 보기용 함수에서 날짜 토큰 값만 짧은 꼴로 표시 (보내는 글·검사 줄의 날짜 꼴은 그대로. 날짜 계산은 하지 않고 같은 날짜 값의 표시만 바꾼다).

완료 기준 추가: 보기용 데이터 테스트 — 원문 영어면 번역 줄 없음, 칩 날짜 짧은 꼴. 나머지 기준 그대로. `reports/T068-impl.md`에 "재시도" 절을 덧붙이고 멈춘다.
