## 만들 것 (사람 결정 그대로)
1. **위쪽 막대**: 시안처럼 로고·꼬리표·날짜를 왼쪽. 탭(Today·Black Friday rehearsal·Products)·PayPal activity·EN/KO·판매자는 남기되 오른쪽에 작게 모은다 (기능 유지). "Public demo · simulated sends"는 작은 회색 글자.
2. **사건 머리글**: "High · Score 6" 드롭다운을 뺀다.
3. **위험 곡선**: 100%·50% 눈금 글자, 끝점 둘레 연한 원.
4. **손님 메시지**: 가운데 "Carrier: Customs hold" 줄을 뺀다. 말풍선은 흰 바탕 실선, 아래 한 줄 "Translated · 영어 · 날짜". 태그는 "AI read" + 2개만. 데모 데이터 말풍선은 끝에 작은 "Demo data" 하나만.
5. **선택지 카드 아래 두 줄**("It's not lost… A1→A2", "PayPal data only…")을 뺀다. "PayPal data only: refund" 문장은 Details 안 첫 줄로.
6. **답장 칸**: 알약 안 Assumption 배지를 뺀다 (Assumption은 반응 막대 쪽 하나만). 체크 칩 줄은 "As you type · N good" + ✓ 칩, 경고 칩은 빨강 글자 칩, 오른쪽에 "Details ⌄".
7. **Details ⌄** 펼치면: "PayPal data only" 한 줄(첫 줄), 역번역(영어), 검사 3개(Facts match·No new promises·Follow-up date).
8. **한국어 미리보기**: 회색 바탕 `#F6F7F9`, 테두리 없음, 제목 "She'll see (Korean)" (구매자 언어 이름은 데이터에서 — 지호 등도 같은 규칙).
9. **검사 줄 제거 + 안전장치**: 검사 실패 → Send 꺼짐 + Details 자동 펼침 + 실패한 검사가 보임. "Simulated send" 작은 글씨는 Send 왼쪽.
10. **Show history** 펼친 모양, 간격·모서리·그림자·글자 크기는 시안 값.
11. 지호·Mike 상세, Products, 서랍, /listing도 같은 규칙(배지 3종, 칩 줄)으로 어긋나지 않게.
