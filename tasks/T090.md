> **가장 중요한 규칙**
> 1. **데이터·안전장치는 예외** — 숫자는 엔진·데이터 그대로, 데모 모드·보내기 관문·승인 버튼 그대로. **검사 줄은 화면에서 빼서 Details 안으로, 검사에 실패하면 Send를 막고 Details를 자동으로 펼친다.**
> 2. 출처 표시는 "AI" 알약(시안 모양) + 숫자 옆 "Assumption" + 데모 데이터 옆 "Demo data"만. "Code decides / AI suggests" 점선 배지는 화면에서 뺀다.
> 3. 이 태스크는 **배치·모양**만. 누르면 일어나는 새 동작(카드 고르기 재계산, Add/Remove 칩, Send 뒤 진행)은 T091·T092가 한다 — 자리만 시안 모양으로 둔다.
> 4. 실제 AI·PayPal 호출 금지, 개발 서버 금지. `.env` 읽지 않음.

## 만들 것
1. **위쪽 막대**: 로고·꼬리표·날짜 왼쪽. 탭(Today·Black Friday rehearsal·Products)·PayPal activity·EN/KO·판매자는 오른쪽에 작게 (기능 유지). "Public demo · simulated sends"는 작은 회색 글자.
2. **사건 머리글**: "High · Score 6" 드롭다운 제거 (위험은 곡선이 보여 준다).
3. **위험 곡선**: 100%·50% 눈금 글자, 끝점 둘레 연한 원.
4. **손님 메시지**: 가운데 "Carrier: Customs hold" 줄 제거. 말풍선 흰 바탕 실선, 아래 한 줄 "Translated · 영어 · 날짜". 태그는 "AI read" + 2개만. 데모 데이터 말풍선은 끝에 작은 "Demo data" 하나만.
5. **선택지 카드 아래 두 줄** 제거 ("It's not lost… A1→A2", "PayPal data only…"). "PayPal data only: refund" 문장은 Details 첫 줄로.
6. **답장 칸**: 알약 안 Assumption 제거 (Assumption은 반응 막대 쪽 하나만). 칩 줄 "As you type · N good" + ✓ 칩, 경고 칩은 빨강 글자, 오른쪽 "Details ⌄".
7. **Details ⌄**: "PayPal data only" 한 줄 → 역번역(영어) → 검사 3개(Facts match·No new promises·Follow-up date). (칩별 %p는 T091이 더한다)
8. **한국어 미리보기**: 바탕 `#F6F7F9`, 테두리 없음, 제목 "She'll see (Korean)" (구매자 언어 이름은 데이터에서).
9. **검사 줄 제거 + 안전장치**: 검사 실패 → Send 꺼짐 + Details 자동 펼침 + 실패한 검사가 보임. "Simulated send" 작은 글씨는 Send 왼쪽.
10. **Show history** 펼친 모양(시안: 날짜·사건·빨간 "Before DisputeLess" 태그 — 사건은 실제 시드·샌드박스 기록만, 없는 사건 금지), 간격·모서리·그림자·글자 크기 시안 값.
11. 지호·Mike 상세, Products, 서랍, /intro, /listing도 배지 3종 규칙으로.
