## 목표 (원문 9장, SPEC v2 8장)
`simulate(input, params?, rules?)` → `SimResult` (`SimulateFn`). 남은 재고로 미래 500개를 '지금 그대로'와 '처방 적용'으로 같은 난수에 두 번 돌려 평균·P10~P90·분쟁 수·분포·처방별 폭포를 낸다.

## 정해진 것
- 상품별 고정 시드, 같은 입력이면 항상 같은 결과 (`Math.random` 금지)
- Before·After가 같은 난수 (common random numbers)
- 주문마다 세부 유형 순서대로 `난수 < 기본 확률 × 처방 배수`이면 분쟁, 주문당 최대 1건
- 대응: 지금 습관 = 50% 전액 환불 / 50% 다투기, 합의 우선 정책 = 기대 손실 최소 수 (T004 함수 재사용)
- 확률·배수는 `config/params.json`의 `productRates`, `fixes`, `habitRefundShare`. 화면에는 'Assumption' 배지 (Q5 승인)
- 처방 토글 후 재계산 0.5초 이내 (원문 F4)
