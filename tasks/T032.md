## 고칠 것
1. **[필수] 기본 모델을 `claude-opus-5-5`로.** 지금 `DEFAULT_LLM_MODEL = 'claude-opus-5'`다. 현재 Claude API 문서의 모델 표에 `claude-opus-5-5`가 있고 기본 모델로 쓰라고 되어 있다 (구현 세션이 읽은 문서 사본이 오래된 판이었다. 컨트롤 타워와 검증자가 현재 판으로 확인함). 이 모델 ID는 날짜 접미사 없이 그대로 쓴다. `LLM_MODEL` 환경 변수로 덮어쓸 수 있는 것은 그대로. 주석의 "표에 없다"는 설명을 지우고, 이 요청 모양이 `claude-opus-5-5`와 맞는 이유를 한 줄로 적는다: `thinking`을 보내지 않음(이 모델은 생각을 끌 수 없고 `effort`로만 조절), `effort`를 명시(이 모델의 기본값은 `medium`), 강제 `tool_choice` 없음, 거절 시 `fallbacks: 'default'`
2. **[필수] 개인통관고유부호 변형 표기 가리기.** 지금은 `P123456789012`와 소문자만 가린다. `P 1234 5678 9012`, `P1234-5678-9012`, `P-123456789012`, 전각(`Ｐ１２３４５６７８９０１２`), 숫자 사이에 공백·하이픈·점이 섞인 꼴도 LLM에 보내기 전에 `⟦PCCC⟧`로 가린다 (`P`/`p`/전각 P + 숫자 12개, 사이에 공백·`-`·`.` 허용). `Cause.evidence`·`causeNote`·로그·예외에도 원문이 남지 않게 한다 (LLM이 근거 낱말로 되돌려 준 값도 같은 가림을 한 번 더 거친다). 13자리 이상 숫자열(전화번호, 추적번호)을 잘못 가리지 않게 경계를 둔다
3. **[필수] 제한 시간.** LLM 호출에 제한 시간이 없어 SDK 기본값(10분)× 재시도 × 분류기 재요청까지 기다릴 수 있다. 화면이 분쟁 하나를 여는 동안 기다릴 수 있는 시간이 아니다. SDK 클라이언트 옵션으로 제한 시간과 재시도 횟수를 정한다: 환경 변수 `LLM_TIMEOUT_MS`(기본 20000), `LLM_MAX_RETRIES`(기본 1). **`claude-api` 스킬 문서의 "Client config" 설명(TypeScript는 밀리초)을 먼저 읽고** 그 옵션 이름을 쓴다. 제한 시간에 걸리면 분류기는 기본 유형 + `needsReview`로 돌아간다 (예외 없음)
4. **[필수] 다시 묻지 않을 오류.** 지금은 거절이 아닌 모든 예외에 한 번 더 묻는다. 설정 오류(키 없음), 인증 오류(401), 권한 오류(403), 잘못된 요청(400)은 다시 물어도 같은 결과이므로 **재요청하지 않고** 바로 기본 유형으로 간다. 다시 묻는 것은 스키마 위반·깨진 JSON·`max_tokens` 잘림·일시적 오류(429, 5xx, 연결 오류, 제한 시간)뿐이다. SDK의 타입 있는 예외 클래스로 구분한다
5. **[권장] `causeNote`는 요약으로.** 통관 보류(A2) 규칙의 `causeNote`가 추적 이벤트 한 줄 전체다. 80자 이내로 자르고 개인통관고유부호 가림을 거친다
6. **[권장] 메시지 본문의 이메일·전화번호.** 구매자 메시지에 이메일 주소나 전화번호가 들어 있으면 LLM에 보내기 전에 `⟦EMAIL⟧`·`⟦PHONE⟧`으로 가린다 (SPEC 3장: 프롬프트에 구매자 이메일·주소를 넣지 않는다). 주소는 모양으로 가리기 어려우므로 하지 않고 보고서에 한계로 적는다

## 그대로 둘 것 (컨트롤 타워 결정)
- 표에 없는 reason의 기본 유형은 지금대로 B3 + `needsReview: true`
- 거절(`stop_reason: refusal`)은 재요청 없이 기본 유형으로
