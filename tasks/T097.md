## 만들 것
- `scripts/design/inventory.ts`: 세 파일 `docs/design/mockup-v4/Desk.dc.html`, `scene1/Scene1.dc.html`, `scene3/Main.dc.html`을 읽어 표 다섯 개를 만든다. 파일마다 절을 나눈다.
  1. **색 토큰**: 인라인 `style`·`<helmet><style>`·로직 문자열 안의 색 값(#hex·rgba·linear-gradient) — 값, 나온 횟수, 첫 자리(요소/클래스/속성).
  2. **모션·타이밍**: `@keyframes` 이름·내용, `animation`, `transition`, `setTimeout`/`setInterval`(ms·하는 일 근처 코드 한 줄), `animation-delay`.
  3. **누를 수 있는 것과 결과 상태**: `onClick`·`pick`·`run`·핸들러 이름 → 그 안의 `setState({...})` 키들 (`phase`·`path`·`draft`·`sel`·`sku`·`done`·`histOpen` 등).
  4. **접힘·펼침**: `sc-if` 조건·`*Open` 상태·`more/less`·rotate.
  5. **조건부 스타일**: 값에 따라 바뀌는 색·스타일(삼항식 안의 색, `riskCol` 같은 함수) — 식 원문 한 줄.
  - hover·focus 규칙(`:hover`·`:focus`)도 2번 또는 별도 표에.
  - 각 행 끝에 빈 칸 두 개: **상태**(`구현함` / `예외`) · **근거**(구현 파일·시험 또는 예외 이유 — DECISIONS 22:55의 예외 목록 중 무엇인지).
- 출력: `reports/design-match/inventory.md` (맨 위에 만든 시각·시안 파일 해시, 행 수). 같은 시안이면 같은 출력 (정렬 고정).
- 다시 돌릴 때 이미 채운 상태·근거 칸을 지우지 않게 (행 키 = 파일 + 종류 + 값/이름) 합친다.
- `npm run design:inventory` 같은 명령은 package.json을 고칠 수 없으면 `npx tsx scripts/design/inventory.ts`로 안내.
