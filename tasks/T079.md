## 만들 것
1. **어댑터 6개를 실제 함수로** (`reports/T076-impl.md` 표대로):
   - `loadRiskCurve` → `riskCurve(events, board, P, R, model, { calibration })` — **답장 예측과 같은 보정 값**(`forecastReply`의 기본 초안 보정)을 넘긴다 (T075 보고서)
   - `loadWeeklySummary` → `weeklySummary(...)`: `aiDrafts`는 **AI 캐시 파일(`data/ai-cache/llm-cache.json`)에서 초안 응답(`draft_en` 칸이 있는 항목) 수**를 센다 — 서버 전용 작은 함수, 셈이지 계산이 아님. 캐시가 없으면 0이 아니라 칸 숨김
   - `loadMoveForecasts` → `forecastMoves(...)` (선택지 카드 차지백 %, 막힌 수 null)
   - `forecastReplyClient` → `forecastReply` (입력칸이 바뀔 때마다 브라우저에서. 브라우저 묶음에 서버 전용 코드·비밀값이 들어가지 않게 — 엔진 순수 함수와 설정 JSON만)
   - `detectReplyFeaturesClient` → `detectReplyFeatures` (As-you-type 칩)
   - `loadHistorySummary` → `summarizeCaseHistory` — **사건 글 속 사람 이름은 넘기기 전에 `⟦BUYER_NAME_1⟧` 토큰으로 바꾼다** (T077 검증). AI 캐시 만들기 스크립트가 도는 `loadCase` 경로 안에서 부른다 (이미 그 자리)
2. **/intro 정리**: 루트 layout이 `/intro`에서 위쪽 막대와 Today 데이터 읽기(PayPal 조회)를 **하지 않게** 한다 (라우트 그룹으로 나누거나 layout에서 경로를 보고 건너뛰기 — 고른 방법을 보고서에). T078의 덮개(position:fixed)는 필요 없으면 걷는다 (`src/app/intro/**` 수정 허용).
3. **이번 주 카드 Demo data 배지**: 보라 카드 위에서 흰 상자로 보인다 (`reports/screens/T076/`) — 어두운 바탕용 배지 모양(테두리·글자색)으로. 배지 모양 규칙 테스트는 유지.
4. 예측 칸에 Assumption 배지가 붙어 있는지 확인 (위험 %·반응 막대·기대 비용·선택지 차지백 %).
