## 배경
실제 샌드박스의 합의 단계 분쟁(서연 D2)에는 `send_message`와 `provide_evidence` 링크가 함께 온다. 지금 `fightApiMove`는 `provide_evidence`가 있으면 항상 그것을 고르는데, 증빙 제출은 아직 실행하지 않는 기능(P1)이라 `executeMove`가 거부한다. 그래서 서연 답장이 `send-message`로 나가지 않는다.

## 수정 가능 폴더
- `src/engine/policy.ts`
- `tests/unit/` 중 엔진 테스트 (`recommend.test.ts`, `plan.test.ts`, 필요하면 `autopilot.test.ts`·`sim.test.ts`)

이 밖은 수정하지 않는다. `tests/acceptance/`는 실행만 한다.

## 고칠 것
`fightApiMove(board)`를 SPEC v2.4 5장 표 순서대로:
1. `board.stage === 'INQUIRY'`이고 `send_message`가 허용되면 → `send_message` (`provide_evidence`가 함께 있어도)
2. 아니고 `provide_evidence`가 허용되면 → `provide_evidence`
3. 아니고 `send_message`가 허용되면 → `send_message`
4. 둘 다 없으면 `null`

기대 손실 계산(금액·확률)은 건드리지 않는다. 이 변경으로 **어떤 수의 `expectedLossCents`도 바뀌면 안 된다.**
