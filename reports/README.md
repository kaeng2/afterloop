# reports

작업 세션은 작업이 끝나면 여기에 보고서를 하나 쓰고 멈춘다. 파일 이름: `T0xx-<YYYYMMDD-HHMM>.md`

## 보고 형식

```markdown
# T0xx 보고 (<YYYY-MM-DD HH:MM>)

- 기준 SPEC: v?   (시작할 때 SPEC.md 첫 줄과 같았는지: 예/아니오)
- 브랜치 / 마지막 커밋: lane/<레인> / <커밋 해시>

## 결과
완료 / 일부 완료 / 막힘 — 한두 문장

## 바뀐 파일
| 파일 | 내용 |
|---|---|

## 테스트 결과
| 명령 | 통과 | 실패 | 비고 |
|---|---|---|---|
| npm run test:acceptance (관련 AC만 적어도 됨) | | | |
| npm test | | | |
| npx tsc --noEmit | | | |

실패가 있으면 실패한 테스트 이름과 원인을 적는다.
```
