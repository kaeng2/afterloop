# reports

작업 세션은 작업이 끝나면 여기에 보고서를 하나 쓰고 멈춘다.

| 파일 | 누가 | 내용 |
|---|---|---|
| `T0xx-impl.md` | 구현 세션 | 아래 "보고 형식" |
| `T0xx-verify.md` | 검증 서브에이전트 (코드 수정 금지) | 판정(통과 / 실패), 실행한 명령과 결과, SPEC·지시서 대조 표, 발견한 문제 |
| `STATUS.md` | 컨트롤 타워 | 작업이 끝날 때마다 한 줄 |
| `review-<YYYYMMDD>-<회차>.md` | 심사위원 리뷰 세션 (읽기 전용) | 리뷰 결과 |

## 보고 형식

```markdown
# T0xx 보고 (<YYYY-MM-DD HH:MM>)

- 기준 SPEC: v?   (시작할 때 SPEC.md 첫 줄과 같았는지: 예/아니오)
- 브랜치 / 마지막 커밋: lane/<레인> / <커밋 해시>

## 결과
완료 / 일부 완료 / 막힘 — 한두 문장

## 테스트 결과

|---|---|---|---|

| npm test | | | |
| npx tsc --noEmit | | | |

실패가 있으면 실패한 테스트 이름과 원인을 적는다.
```
