## 찍은 방법과 정정
- 1440 폭은 헤드리스 Chrome으로 찍었다.
- **390 폭은 앱 안 브라우저의 390 × 844 뷰포트로 찍었다.** 헤드리스 Chrome은 창 폭을 약 500 아래로 줄이지 못해서, 1차 때 올린 390 스크린샷은 500 폭으로 그린 화면의 왼쪽 390만 잘라 낸 것이었다. **1차에서 "390에서 상자가 잘린다"고 한 것은 이 캡처 방식 탓일 수 있다** (1차 코드의 실제 390 모습은 확인하지 못했다). 지금 코드는 390 뷰포트에서 가로 넘침이 없다 (문서 폭 390 = 뷰포트 390, 카드 왼쪽 16 · 오른쪽 374).
- 1차 스크린샷 4장은 지웠다 (git 기록 `44d49be`에 남아 있다).
