## 기대값을 적는 방식
시뮬레이션 값을 숫자로 잠글지는 아직 정해지지 않았다 (AC22, SPEC 13장 Q12). 그래서 이 초안의 기대값은 **"같은 입력으로 엔진을 불러 얻은 값과 같다"** 로 적는다. 아래 "참고 값"은 초안 작성 때 고정 사본으로 `simulate`를 불러 얻은 것이고, 테스트에 적지 않는다.

참고 값 (가디건 `FK-CD-OAT`, 처방 4개): 지금 그대로 평균 21619¢ · P10 6700¢ · P90 36000¢ · 분쟁 4.46건 → 처방 적용 평균 4366¢ · P10 0¢ · P90 10380¢ · 분쟁 2.07건. 폭포 21619 → 16982 → 10354 → 8826 → 4366. 지금 그대로 평균이 큰 순: 비니 세트 25460, 가디건 21619, 코트 13651, 스웨터 10988.

## 확인 필요 (사람이 정한다. 기대값을 지어내지 않았다)
1. **점 그림.** 리뷰가 승인되면 점 그림이 이 화면의 주인공이다. 그런데 "미래 500개 중 어느 것을 그릴지" 기준이 없다 (T013 선행 2). 기준이 정해지면 항목을 더한다: "빨간 점의 수 = 그 미래의 분쟁 수", "오른쪽 빨간 점은 왼쪽 빨간 점의 일부다" (같은 난수, SPEC 8장).
2. 폭포의 처방별 절감액과 감소 비율 (예: "약 80% 감소")을 화면에 적을지. 적는다면 그 값을 내주는 엔진 함수가 먼저 있어야 한다.
3. 색상 문구 (T020)가 있을 때의 기대값: 4개 언어, 역번역, 한국어 한 줄이 먼저 (리뷰). T020 뒤에 정한다.
4. 시뮬레이션 값을 숫자로 잠글지 (AC22, Q12). 잠그면 1번에 참고 값을 그대로 적을 수 있다.
5. 분쟁 수 표기 자리수 (4.46 → "about 4.5"?)와 금액 반올림 (21619¢ → "$216").
6. 금지 문구의 영어 목록 (AC18 초안 확인 필요 3과 같다).
