## 확인 필요 (남은 것. 기대값을 지어내지 않았다)
1. **건너뛴 분쟁의 추천 칸.** `recommend(D3_REAL, P, R).best`는 `refund` 3700¢다 (허용된 수가 `accept_claim`뿐이라서. `recommend`를 불러 확인함). 악용 의심으로 건너뛴 행에 "Full refund"를 추천처럼 보일지. T012의 기본은 "추천을 감추고 Review yourself만". 정해지면 6번에 넣는다.
2. 점수가 같을 때의 정렬 순서 (T012의 기본: 기한 빠른 순 → 분쟁 번호)와 문의 행의 위험 점수.
3. **Yuki 자동 답변 줄** (`auto` / `common_questions`). T021 뒤에 항목을 더한다. 기대 문장은 그때 정한다.
4. 지호·Mike의 위험 신호 값과 점수 (T044·T043 뒤).
5. **로그 문장 안의 금액.** 엔진이 만든 문장은 센트까지 적는다 (`($36.80)`, `($19.53)`). 같은 화면의 추천 칸은 `$37`·`$20`이다. 로그를 엔진 문장 그대로 둘지 (3번 항목의 전제), 엔진 문장을 고칠지.
6. 금지 문구의 영어 목록 (AC18 초안 확인 필요 3과 같다), 로그 줄의 시각 표기.
