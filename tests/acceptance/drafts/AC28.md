## 확인 필요 (남은 것. 기대값을 지어내지 않았다)
1. **O04 줄을 보일지 숨길지.** T016의 기본은 SPEC 9-3대로 회색 제외 줄이다. 숨기기로 하면 2·7·11번의 미등록 수와 제외 행 목록이 바뀐다 (누를 수 있는 건수 2는 그대로).
2. 가상 추적번호에 'Demo data' 배지를 붙이고 README 정직성 표에 넣을지 (SPEC 10장의 시연용 데이터 4가지에는 없다).
3. 실제 등록 스위치의 변수 이름.
4. 상태 코드 표기. 실제 응답은 201이었다 (`DECISIONS.md` 2026-11-10 추적번호 7건). SPEC 9-3 예시 문구는 "· 200"이다. 8번은 "받은 코드 그대로"를 전제로 썼다. 성공 코드가 섞이면 요약 줄에 무엇을 적을지.
5. T011이 내놓는 결과의 꼴과 추적번호의 출처. T011 지시서가 정본이다.
6. 금지 문구의 영어 목록 (AC18 초안 확인 필요 3과 같다).
