## 확인 필요 (사람이 정한다. 기대값을 지어내지 않았다)
1. **답장 계획의 실행 API.** 실제 D2의 허용된 수에는 `provide_evidence`가 있다. 이 값을 `D2_BASE.allowedMoves`에 그대로 넣으면 `recommend(D2_AFTER).best.apiMove`는 `provide_evidence`이고 `executeMove`는 거부한다 (초안 작성 때 확인). `send_message`로 나가게 하는 방법이 정해져야 6번의 `canSend`, 9~11번의 "계획" 입력, 그리고 "후 칸의 실행 API" 기대값을 적을 수 있다 (T009 선행 A).
2. 금액 표기: `$74.00`·`$36.80` (사람 지시, 기본) 또는 `$74`·`$37` (리뷰 권장). 1번 항목은 센트 값으로 비교하므로 어느 쪽이든 그대로다. 표기 항목을 더할지는 결정 뒤에.
3. 금지 문구 목록: SPEC 10장은 "보장"·"예측 정확도"다. 영어 목록 (제안: `guarantee`, `guaranteed`, `prediction accuracy`, `accurate prediction`)은 사람이 정한다.
4. 초안·전송본 문장과 날짜 값 (공용 입력의 "사람 확인 필요").
5. 어조 판정이 없을 때 (`angryTone: null`) 지금 점수는 5 (High)로 나온다. 이 경우를 항목으로 넣을지.
